Expands OliBomby's Mapperatorinator "Add to Beatmap" feature into a new tab called "Inpaint". Lets you preview and finetune maps quickly. Makes use of osu parsers and Danser for previews.


Credits:

Mapperatorinator (OliBomby): https://github.com/OliBomby/Mapperatorinator

Danser (Wieku): https://github.com/Wieku/danser-go

osu parsers (kionell): https://github.com/kionell/osu-parsers
